# Persist picker-authorized folders

The index must survive a restart, but the webview must never gain path access. Folio stores the folders that the user chose in the native picker and can reopen them by workspace id alone. Reopening is refused if the folder has gone, lost permission or now resolves elsewhere. A workspace is currently one active folder at a time; searching several folders together is deferred. Document identity follows the frozen contract (`workspaceId:relativePath`, docs/contracts.md), which supersedes this ADR's earlier opaque-id choice. A rename or move therefore yields a new document identity; history records the before and after paths, and the content hash connects the two. Changes made outside Folio are detected when the folder is scanned or refreshed, not by a live watcher. If re-extracting a changed file fails, the previous index entries stay in place and the document is marked stale rather than silently dropped.

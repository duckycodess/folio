# Synthetic demonstration corpus

All names, events, and document contents here are fictional examples for Folio. Fifteen TXT/Markdown documents and one text-based PDF (`research/consent-form-guide.pdf`, two pages) include English, Filipino, Taglish, explicit cross-folder references, one byte-identical duplicate, and an unrelated event sharing the same date. They are not private user documents.

The deadline change should flag relevant Community Learning Project passages without changing the unrelated mathematics practice date. The duplicate copy should be detected by content hash. Project-plan-copy contains relative links inherited from its original folder; broken links in that copied location must not be invented as valid references.

The benchmark file contains labels, not model results.

The PDFs are generated by `cargo test --manifest-path src-tauri/Cargo.toml -- --ignored write_pdf_fixtures`. `scanned/scanned-sample.pdf` has an image and no text layer; it sits outside `documents/` and must be reported as unsupported, not indexed. The browser preview loads only the TXT/Markdown fixtures.

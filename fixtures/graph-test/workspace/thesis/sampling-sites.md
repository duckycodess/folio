# Sampling Sites

All six sites are along the Binangonan shoreline of Laguna de Bay.

1. Site A - Barangay Wawa fish port
2. Site B - Barangay Wawa fishpen edge
3. Site C - Barangay Kalinawan creek mouth
4. Site D - Barangay Libid boat landing
5. Site E - Barangay Pila-Pila shoreline
6. Site F - Barangay Tayuman reference point (control site)

Site F is the control because it is farthest from fishpens and household outfalls.
